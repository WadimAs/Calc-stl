# STL Вага

Android-додаток (Flutter): перегляд **STL** і **3MF** у 3D та розрахунок ваги пластику для друку за справжнім пошаровим нарізанням.

## Що вміє

- Відкриває бінарні та ASCII STL, а також 3MF (PrusaSlicer, Bambu Studio, OrcaSlicer, Cura — з компонентами, трансформаціями й одиницями виміру).
- Відкриття файлу кнопкою або з Telegram / файлового менеджера через «Відкрити за допомогою» та «Поділитися».
- 3D-перегляд: один палець — обертання, два — масштаб і зсув, подвійний дотик — скинути вид.
- Нарізання у фоні з прогресом; при зміні налаштувань перераховує автоматично.
- Результат: вага (г), довжина філаменту (м), об'єм пластику, кількість шарів, вага суцільної моделі.
- Налаштування: висота шару та першого шару, ширина лінії, стінки, верхні/нижні шари, заповнення, масштаб, кількість копій, матеріал (PLA, PETG, ABS, ASA, TPU, PA, PC, …) або своя густина, діаметр 1,75 / 2,85. Зберігаються між запусками.

## Як рахується вага

Модель ріжеться на шари. Кожен шар розтеризується (правило ненульового обходу, тож перекриті об'єкти зливаються) і ділиться на:

1. **Стінки** — усе, що ближче до контуру, ніж `стінки × ширина лінії` (карта відстаней).
2. **Суцільне дно/верх** — ділянки, над якими або під якими протягом N шарів немає матеріалу.
3. **Розріджене заповнення** — решта площі × відсоток заповнення.

Площа растра коригується до точної площі полігонів шару. На тестових фігурах (куб, труба, куля) розбіжність з аналітичним розрахунком < 1 %. Порівняно зі слайсерами очікуйте ±5–10 %, залежно від візерунка заповнення.

**Не враховуються:** підтримки, кайма (brim), спідниця, очищувальна вежа, перекриття ліній.

## Збірка APK через GitHub (без комп'ютера)

1. Створіть новий репозиторій на GitHub і завантажте вміст цієї папки (зі збереженням структури, включно з `.github/`).
2. Вкладка **Actions** → workflow **Build APK** запуститься сам (або **Run workflow**).
3. Через ~6–8 хв відкрийте завершений запуск → розділ **Artifacts** → `stl-weight-apk` → всередині `stl-weight.apk`.
4. Щоб отримати APK як реліз: створіть тег `v1.0.0` — файл з'явиться на сторінці **Releases**.

## Збірка локально

```bash
flutter create --platforms=android --org com.printcalc --project-name stl_weight .
rm -f test/widget_test.dart
flutter pub get
flutter test
flutter build apk --release
```

`flutter create .` лише додає відсутні стандартні файли Gradle, наявні файли не перезаписуються.

## Структура

```
lib/
  main.dart                 — тема та запуск
  ui/home_page.dart         — головний екран
  ui/settings_sheet.dart    — усі налаштування
  viewer/model_viewer.dart  — 3D-рендер (CustomPainter + drawVertices)
  mesh/stl_parser.dart      — STL
  mesh/threemf_parser.dart  — 3MF
  mesh/zip_reader.dart      — власний ZIP-читач (deflate, ZIP64)
  mesh/loader.dart          — завантаження в ізоляті, спрощення для перегляду
  slicer/slicer.dart        — нарізання та розрахунок об'єму
  slicer/slice_runner.dart  — фоновий запуск зі скасуванням
  slicer/settings.dart      — налаштування й матеріали
  platform/files.dart       — зв'язок з Android (вибір файлу, intents)
android/app/src/main/kotlin/.../MainActivity.kt
test/slicer_test.dart       — тести нарізання та парсерів
```

Сторонніх пакетів немає — лише Flutter SDK.

## Далі: калькулятор вартості

`SliceResult` вже містить об'єм, а вага рахується як `result.grams(density, copies: n)`. Для калькулятора вартості знадобиться ще оцінка часу друку — її найпростіше додати в `slicer.dart`, підсумовуючи довжину ліній кожного шару та ділячи на швидкості.
